# Hammad Portfolio

Static personal portfolio for Hammad Shakeel, focused on client-ready web experiences, Flutter products, backend APIs, and practical automation.

## Technologies

- Semantic HTML
- CSS with responsive breakpoints and reduced-motion support
- Vanilla JavaScript for accessible navigation and scroll reveals
- GitHub Pages for hosting

## Run locally

No build step is required. From the repository directory, serve the files with any static web server, for example:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

Opening `index.html` directly also works, but a local server better matches GitHub Pages behavior.

## Featured projects

- [GPA Calculator](https://hammaddev407.github.io/Gpacalculator1/) — live JavaScript GPA/CGPA calculator with configurable grading thresholds.
- [Pakistani Restaurant Website](https://hammaddev407.github.io/Restuant-website/) — interactive menu with category filters, generated dish cards, cart sidebar, subtotal, and checkout call to action.
- [Glow Haven Cosmetics](https://hammaddev407.github.io/Cosmatic-Website/) — dark cosmetics storefront experience with product rendering, bag interactions, and totals.

The links above were reachable during the portfolio audit. Their interactive behavior is maintained by their separate repositories. The portfolio describes only behavior verified from those project sources and live pages; it does not claim production commerce, authentication, or payment processing.

Math Batch is not currently listed because no matching public repository or verified deployment was found during the audit.

## Contact workflow

The site uses direct email, phone, LinkedIn, and GitHub links. It does not include a client-side contact form or embedded API credentials. A serverless form can be added later when a delivery provider and privacy requirements are selected.

## Deployment

The site can be deployed as a static GitHub Pages site from the repository's main branch. The portfolio only depends on files in this repository and externally hosted Google Fonts/Font Awesome assets.
